# Multiple sources and drag ordering

Run from the repository root with Playwright and Chrome available:

```
node tests/multiple-sources-browser.cjs
```

The test intercepts every request and keeps configuration writes in memory. It never writes production configuration. It verifies non-adjacent checkbox choices in screen and Design editors, deselection, all three zone source types, persistence after reload, pointer drag ordering with durations retained, concatenated playlists, media sequences, isolated clock updates and legacy `sourceId` layouts.

Zones save `sourceIds` plus the first selection in legacy `sourceId`. An explicit empty array means no source. Multiple playlists concatenate their active contents in selection-list order and retain per-playlist duration overrides. A single widget stays continuously visible; multiple widgets cycle using their durations. Selection does not require modifier keys. Playlist handles support pointer dragging with scroll near list edges; arrow buttons remain available.

The player bundle is generated by `npm run build:player` and checked for ES5 syntax. Screenshots from the browser test are written under `/tmp` for visual verification.
